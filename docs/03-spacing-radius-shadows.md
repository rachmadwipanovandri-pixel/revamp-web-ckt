# Border Radius & Shadows

## Border Radius Scale
| Token | Value | Likely Use |
|---|---|---|
| radius-xs | 1px | hairline elements |
| radius-sm | 3px | small chips/badges |
| radius-sm-alt | 3.576px | icon containers (scaled) |
| radius-md | 5.96px | cards (scaled) |
| radius-lg | 8px | buttons, inputs, cards |
| radius-lg-alt | 9.536px | cards (scaled) |
| radius-xl | 11.92px | large cards (scaled) |
| radius-full | 50% | avatars, dots, circular icons |

## Shadows
- **Card / elevated surface shadow:**
  `0px 0.6px 2.5px -1.2px rgba(0,0,0,0.17), 0px 2.3px 9.6px -2.3px rgba(0,0,0,0.15), 0px 10px 42px -3.5px rgba(0,0,0,0.08)`
- **Inset highlight (glass/border effect):**
  `0px 0px 0px 1px rgba(255,255,255,0.55) inset`
