# Typography

## Font Families
- **Primary UI font:** `"Google Sans Flex", "Google Sans Flex Placeholder", sans-serif`
- **Secondary / numeric font:** `"Roboto Flex", -apple-system, sans-serif`
- **System fallback stack** (used on some buttons/links): `system-ui, -apple-system, sans-serif`

## Type Scale

| Use | Font Size | Weight | Line Height | Color |
|---|---|---|---|---|
| Heading (large) | 36px | 700 (Bold) | 44px | `#101828` |
| Heading (default) | 30px | 700 (Bold) | 40px | `#101828` |
| Body (large) | 18px | 400 (Regular) | 28px | `#101828` |
| Body (default) | 16px | 400 (Regular) | 24px | `#101828` |
| Button label | 12px | 600 (Semibold) | 14.4px | `#ffffff` on filled buttons |
| Small link / caption | 12px | 400 (Regular) | normal | `#0f172a` / `#000000` |

## Notes
- Headings and body copy consistently use "Google Sans Flex" with normal letter-spacing.
- Buttons use a semibold (600) weight at a small 12px size with tight line-height.
- No custom letter-spacing overrides were detected (all computed as `normal`).
